# Ease-Space-
EaseSpace is a student wellness and personal growth website that helps students manage their mood, stress, focus, goals, journaling, reflection, and communication through simple interactive activities.

Features

EaseSpace includes a mood tracker that allows users to select their current mood and receive a supportive message. It also provides a guided breathing exercise and random wellness activities that can help users take short breaks and practice relaxation.
The website includes a focus timer for managing study sessions, along with a reflection section where students can answer questions and save their responses. A communication challenge helps users practice their communication skills through simple activities.
Users can also create personal goals, mark completed goals, and remove goals when required. The journal section allows users to write and save their thoughts and experiences. A progress tracker displays the user's activity progress, while the dark mode option provides an alternative website theme.

Technologies Used

EaseSpace is developed using HTML, CSS, and JavaScript. Font Awesome is used for icons, and browser Local Storage is used to save journal entries and reflection responses.

Purpose

The main purpose of EaseSpace is to create a convenient digital space where students can take a break from academic activities, reflect on their experiences, manage their goals, improve their focus, and practice simple wellness activities.

How to Run

Download or clone the repository and open the project folder in Visual Studio Code. Ensure that the HTML, CSS, and JavaScript files are properly connected. Open the index.html file in a web browser to use the website.

Project Status

EaseSpace is a student web development project focused on student wellness and personal growth. The project can be further developed by adding user accounts, database integration, personalized activities, progress history, and additional wellness features.
